# Журнал

Электронный журнал для одной или нескольких учебных групп: оценки по 10-балльной шкале, отметки о пропусках, автоматический средний балл и подсчёт пропущенных пар и часов.

Дополнительно: роль **старосты** с правом вести журнал своей группы, аватарки групп и аккаунтов (эмодзи или фото с телефона), журнал аудита действий администратора, полноэкранный режим журнала, просмотр замен с сайта колледжа, раздел **«Расписание пар и ДЗ»** с листанием недель, настраиваемым временем пар, цветными парами, парами из двух предметов, домашними заданиями по датам и топом активности, а также **виджеты рабочего стола** трёх размеров.

Состоит из двух частей:

- **`server/`** — сервер на Node.js + TypeScript + SQLite. База данных лежит на вашем компьютере.
- **`android/`** — Android-приложение на Kotlin + Jetpack Compose.

Приложение подключается к серверу по адресу, который вы выдаёте через [portmap.io](https://portmap.io/), поэтому журналом можно пользоваться с телефона из любой сети.

## Быстрый старт

### 1. Запустите сервер

Дважды щёлкните **`start-server.cmd`** в корне проекта.

В Linux и macOS запустите **`start-server.sh`** из терминала:

```bash
chmod +x start-server.sh   # один раз, чтобы файл стал исполняемым
./start-server.sh
```

Скрипт сам:

- проверит Node.js (нужна версия 22.5+);
- установит зависимости при первом запуске;
- создаст `.env` из `.env.example`, если его ещё нет;
- запустит сервер на `0.0.0.0:8080`.

Проверка в браузере на этом же компьютере: <http://localhost:8080/api/health>

В консоли сервер также покажет адреса в локальной сети, например `http://192.168.1.18:8080`.

### 2. Откройте доступ через portmap.io

1. Зарегистрируйтесь на <https://portmap.io/>.
2. Создайте конфигурацию и добавьте в неё правило **TCP** с локальным портом **8080** (`localhost:8080`).
3. Скачайте конфигурацию/клиент portmap и подключитесь — сайт показывает пошаговую инструкцию для вашей ОС.
4. Скопируйте выданный адрес. Он может выглядеть так:
   - `https://school-abc123.portmap.io:12345`
   - `http://school-abc123.portmap.io:12345`

Именно этот адрес (вместе с портом, если он есть) нужно ввести в приложении.

> На бесплатном тарифе portmap доступно одно правило и случайный адрес. Адрес может измениться после пересоздания конфигурации — тогда поменяйте его в приложении: **Профиль → Сервер → Изменить**.

### 3. Установите приложение

Готовый отладочный APK: **`zhurnal-debug.apk`** в корне проекта (собирается командой `build-apk.cmd`).

1. Передайте APK на телефон (кабель, облако, Telegram и т. п.).
2. Разрешите установку из неизвестных источников для приложения, через которое открываете файл.
3. Установите и откройте **«Журнал»**.
4. Введите адрес сервера из portmap.io и нажмите **«Проверить и подключиться»**.

После этого войдите под нужным аккаунтом.

## Как пользоваться

### Администратор

- **Группы** — создание групп, кодов регистрации и аватарок.
- **Предметы** — предмет закрепляется за группой и преподавателем.
- **Люди** — создание аккаунтов преподавателей, обучающихся, старост и других администраторов, сброс паролей, смена аватарок, отключение и удаление аккаунтов.
- **Журнал аудита** — кнопка в разделе управления: видно, кто и когда создавал группы, аккаунты и предметы, добавлял пары, менял оценки, пропуски, аватарки и пароли. Записи можно фильтровать по типу и искать по тексту.
- Может открыть журнал любой группы и редактировать отметки.

### Преподаватель

- Видит только свои группы и свои предметы.
- Создаёт пары (дата + номер пары + тема), редактирует и удаляет их.
- Выставляет оценки 1–10, отмечает отсутствие «Н» и при желании указывает причину.
- Ведёт журнал своей группы, видит и модерирует домашние задания по своим предметам.

### Староста

- Назначается администратором и закрепляется за одной группой.
- Видит свою группу как обучающийся, но может добавлять пары и выставлять оценки по любым предметам **своей** группы.
- Может модерировать домашние задания своей группы.
- Журнал других групп недоступен; их расписание открывается только для просмотра.

### Обучающийся

- Регистрируется самостоятельно по коду группы.
- Видит только свою группу и только чтение: оценки, пропуски, средний балл и сводку по предметам.
- Может выбрать аватарку в профиле (эмодзи или фото с устройства).
- Видит расписание всех групп, но домашние задания — только своей; может записывать ДЗ и смотреть топ активности.

### Аватарки и замены

- Аватарку можно выбрать из набора эмодзи при создании группы или аккаунта, а также изменить в любой момент: **Профиль → Сменить аватарку**, для группы — в разделе управления.
- В окне выбора аватарки есть кнопка **«Фото с устройства»**: приложение открывает галерею, обрезает фото по центру до квадрата, уменьшает до 256×256 и сохраняет на сервере. Фото подставляется везде, где показывается аватарка.
- На главном экране есть кнопка **«Замены с сайта колледжа»**. Сервер скачивает документ Word со страницы <http://www.bobruisk.belstu.by/students/schedule-substitutions>, разбирает его на абзацы и таблицы с сохранением объединённых ячеек, и приложение показывает замены в виде аккуратной таблицы, которую можно прокручивать по горизонтали. Ответ кэшируется на 10 минут; кнопка обновления сбрасывает кэш.

### Расписание пар и ДЗ

Раздел открывается с главного экрана кнопкой **«Расписание пар и ДЗ»**.

- **Недели.** Сверху закреплён «островок» с датами учебной недели — он остаётся на месте при прокрутке таблицы. Стрелками ← и → можно листать недели вперёд и назад, кнопка «Сегодня» возвращает к текущей. Нижняя неделя — нечётная неделя месяца, верхняя — чётная; рядом показаны номер недели и подсказка, на сколько недель вы отклонились.
- **Таблица.** Слева всегда виден столбец с номером пары и временем. Стандартное расписание: 8:00–9:40, 9:50–11:30, 12:10–13:50, 14:00–15:40, 15:50–17:30, 17:40–19:20, 19:30–21:10, 21:20–23:00. Внутри пары 45 минут + перемена 10 минут + 45 минут; между парами 10 минут, после второй пары — обед 40 минут. Дни идут столбцами, таблицу можно прокручивать по горизонтали. Дни недели подписаны датами, текущий день выделен.
- **Время по дням.** Администратор может задать своё время для каждой пары отдельного дня — например, сокращённые перемены в субботу. Общее время показано в левом столбце, а в ячейке дня выводится его особое время, если оно отличается.
- **Своя и другие группы.** Сначала открывается расписание своей группы (она помечена ★); переключателем сверху можно посмотреть расписание любой другой группы. Чужие домашние задания при этом не показываются.
- **Цвета.** Пару можно выделить одним из цветов (красный, янтарный, зелёный, синий, сливовый, графит) — например, красным отметить пару на полдня. Цвет сохраняется на сервере и виден всем.
- **Редактирование.** Единое расписание ведёт только администратор. В разделе есть кнопка-карандаш **«Режим правки»**: в нём появляются «+» в пустых ячейках, карандаш у существующих пар и кнопка «Время пар». В форме выбираются предмет, день, номер пары, неделя (каждую / верхняя / нижняя), аудитория, заметка и цвет.
- **Пара из двух предметов.** Переключатель **«Разделить на два предмета»** делит квадрат пары по середине на две половины по 45 минут. У каждой половины свой предмет, преподаватель и аудитория; нажатие на половину открывает домашние задания соответствующего предмета.
- **Домашние задания.** Нажатие на предмет открывает его страницу. Любой участник группы может записать задание для всей группы или прочитать уже записанные; под текстом указывается автор и его роль, дата и (если задан) срок сдачи. Автор, староста, преподаватель и администратор могут редактировать и удалять запись.
- **ДЗ привязано к дате.** Задание относится только к конкретному дню выбранной недели и своему предмету: на странице видна дата занятия, а при листании на другую неделю прошлые задания не показываются. Поэтому новая неделя начинается с чистого листа, даже если пара стоит в сетке каждую неделю.
- **Топ активности.** Кнопка с кубком открывает топ участников группы по числу записанных домашних заданий. Итоги переключаются между **неделей** (с понедельника) и **месяцем** (с 1 числа); показываются место, количество записей, время последней записи и прогресс относительно лидера.

### Виджеты рабочего стола

В приложении есть три виджета — добавьте нужный долгим нажатием на рабочем столе → **«Виджеты»** → **«Журнал»**:

- **2×2 «пары на сегодня»** — дата и прокручиваемый список пар на сегодня с временем, предметом и аудиторией.
- **4×2 «средний балл»** — сводка по всем предметам, как в журнале: средний балл по каждому предмету и общий средний балл.
- **4×4 «оценки по предмету»** — пять кнопок-предметов: выберите любой и листайте свои оценки из журнала (дата, тема, оценка или «Н» за пропуск). Список прокручивается, выбранный предмет подсвечивается.

У каждого виджета в правом верхнем углу есть кнопка **↻** для обновления. Данные также обновляются автоматически примерно раз в 30 минут и при открытии приложения. Виджет показывает данные своей группы для обучающегося и старосты; администратору и преподавателю без группы выводится общая сводка сервера. Если нажать на виджет, откроется приложение. Если вы ещё не вошли, виджет подскажет войти в аккаунт.

Средний балл, количество пропущенных пар и часов (1 пара = 2 часа) считаются автоматически.

### Планшеты и полноэкранный режим

- В журнале есть кнопка **«На весь экран»**: скрываются верхняя панель, выбор предмета, статистика и вкладки, остаются таблица и кнопка выхода.
- Окно оценки открывается по центру экрана, содержимое прокручивается, а кнопка **«Сохранить»** всегда закреплена снизу — диалог целиком помещается на телефоне и планшете в альбомной ориентации.

## Сборка APK

Требования уже установлены в `tools/` (JDK 17 и Android SDK 35). Сборка:

```bat
build-apk.cmd
```

Скрипт использует `tools\jdk17` и `tools\android-sdk`, выполняет `gradlew.bat assembleDebug`, копирует результат в `zhurnal-debug.apk` и публикует обновление на сервере (см. ниже).

APK также лежит по пути:

```
android\app\build\outputs\apk\debug\app-debug.apk
```

Параметры сборки: `compileSdk 35`, `minSdk 26`, `targetSdk 35`, версия 1.0.1 (`versionCode 2`), Compose Material 3, пакет `ru.zhurnal.app.debug`.

Если нужно пересоздать окружение сборки с нуля, запустите PowerShell от администратора:

```powershell
powershell -ExecutionPolicy Bypass -File tools\setup-sdk.ps1
```

Если телефон подключён по USB с включённой отладкой, APK можно установить одной командой:

```bat
tools\android-sdk\platform-tools\adb.exe install -r zhurnal-debug.apk
```

### Обновления приложения

При запуске приложение спрашивает у сервера `GET /api/app/update`. Если `versionCode` на сервере больше установленного, показывается экран обновления и войти в приложение нельзя, пока обновление не установлено. APK скачивается с `GET /api/app/download` и открывается системным установщиком (при первом запуске нужно разрешить установку из этого источника). Если сервер недоступен, проверка не блокирует вход.

Файлы обновления лежат на сервере в папке `server/public`:

- `update.json` — версия, описание изменений, размер и SHA-256;
- `zhurnal-debug.apk` — сам файл приложения.

`build-apk.cmd` публикует их автоматически после сборки. Вручную:

```bat
node tools\publish-update.mjs "Что нового в этой версии"
```

Перед выпуском повысьте `versionCode` (и при необходимости `versionName`) в `android\app\build.gradle.kts` — иначе приложение не увидит обновление.

### Проверка API

При запущенном сервере и демо-базе можно прогнать автоматическую проверку:

```bat
node tools\e2e-test.mjs
```

Скрипт проверяет вход, роли, журнал, оценки, пропуски, регистрацию по коду, аватарки, права старосты, журнал аудита, замены, расписание (включая время по дням, пары из двух предметов и привязку ДЗ к дате/неделе), домашние задания, топ активности и публикацию обновлений (195 проверок). Он сам создаёт временную группу, аккаунты, предметы, пары и ДЗ, а в конце удаляет их; демо-данные и реальные группы не затрагиваются.

## Резервная копия базы

Закройте сервер и скопируйте файл `server/data/zhurnal.db` (а также `zhurnal.db-wal`, если он есть). Либо запустите **`backup-db.cmd`** — он сделает согласованный снимок в папку `backups/` даже при работающем сервере.

Восстановление: остановите сервер, замените `server/data/zhurnal.db` файлом из `backups/`, удалите старые `-wal`/`-shm` и запустите сервер.

## Настройки сервера

Файл `server/.env` (создаётся из `.env.example`):

```ini
PORT=8080
HOST=0.0.0.0

# DATA_DIR=./data
# DB_PATH=./data/zhurnal.db

# Если не задан, секрет создаётся в data/jwt-secret.txt
# JWT_SECRET=длинная-случайная-строка

# Используется только при создании самого первого администратора
ADMIN_LOGIN=admin
ADMIN_PASSWORD=admin12345
```

После изменения `PORT` не забудьте поменять локальный порт в правиле portmap.io.

Полезные команды:

```bat
cd server
npm run typecheck      :: проверка типов
npm run build          :: сборка в dist/
npm run serve          :: запуск собранной версии
npm run seed:demo      :: демо-данные (если группы IS21 ещё нет)
```

### Основные эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | проверка сервера |
| POST | `/api/auth/login` | вход |
| POST | `/api/auth/register` | регистрация по коду группы |
| POST | `/api/auth/check-code` | проверка кода группы |
| POST | `/api/auth/change-password` | смена пароля |
| PATCH | `/api/auth/me/avatar` | смена своей аватарки |
| GET | `/api/substitutions` | замены с сайта колледжа (текст + таблицы) |
| GET | `/api/schedule/groups` | группы для выбора в расписании |
| GET | `/api/schedule` | расписание группы на верхнюю/нижнюю неделю; `weekStart` (YYYY-MM-DD) задаёт неделю для ДЗ |
| POST / PATCH / DELETE | `/api/schedule…` | пары, цвета и аудитории (только администратор) |
| PUT | `/api/schedule/times` | своё время пар для выбранного дня |
| GET / POST / PATCH / DELETE | `/api/homework…` | домашние задания группы; `date` у GET и `lessonDate` у POST привязывают задание к занятию |
| GET | `/api/homework/top` | топ активности за неделю или месяц |

## Безопасность и ограничения

- Пароли хранятся в виде bcrypt-хешей, а не в открытом виде.
- JWT действует 120 дней; секрет создаётся автоматически и хранится в `server/data/jwt-secret.txt`.
- Вход ограничен по числу неудачных попыток с одного IP.
- Все изменения групп, аккаунтов, предметов, пар, отметок, расписания и домашних заданий записываются в журнал аудита; читать его может только администратор. Содержимое фото-аватарок в аудит не попадает.
- Единое расписание каждой группы меняет только администратор; староста и преподаватель редактируют журнал и домашние задания.
- Расписание любой группы видно всем авторизованным пользователям, но домашние задания и топ доступны только участникам группы, её преподавателям и администратору.
- Сервер слушает `0.0.0.0:8080` и доступен всем, кто знает адрес туннеля. Используйте HTTPS-адрес portmap, если он доступен, и не публикуйте код группы.
- Это учебный/домашний проект, а не промышленная система: журнал аудита хранится локально и не заменяет резервное копирование и мониторинг.
- Для локальной сети Windows может запросить разрешение брандмауэра для Node.js — разрешите доступ в частных сетях. Для туннеля portmap входящее правило обычно не требуется, так как соединение исходящее.

## Если что-то не работает

**`Node.js не найден`** — установите Node.js 22.5+ с <https://nodejs.org/> и перезапустите `start-server.cmd` (Windows) или `./start-server.sh` (Linux/macOS).

**`Порт 8080 занят`** — закройте старый процесс:

```bat
netstat -ano | findstr :8080
taskkill /PID <PID> /F
```

В Linux/macOS:

```bash
lsof -i :8080
kill <PID>
```

Либо задайте другой `PORT` в `server/.env` и обновите правило portmap.

**Приложение не подключается** — проверьте:

1. сервер запущен и `/api/health` открывается на компьютере;
2. правило portmap указывает на локальный порт 8080;
3. клиент portmap подключён;
4. адрес в приложении введён вместе с портом;
5. телефон имеет доступ в интернет.

**`Неверный логин или пароль`** — проверьте раскладку и регистр логина (логин нечувствителен к регистру, пароль — да).

**Забыли пароль администратора** — остановите сервер и удалите базу (данные пропадут), либо создайте нового администратора через SQLite вручную. Проще держать резервную копию.
